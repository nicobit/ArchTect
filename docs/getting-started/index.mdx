Choose your preferred environment and get modeling in minutes.

## Installation paths

| Environment | Best for | Guide |
|---|---|---|
| **VS Code extension** | Daily use alongside code | [VS Code Extension](/getting-started/vscode-extension) |
| **Browser app** | Quick demos, no install | [Browser App](/getting-started/browser-app) |

## First steps

1. **Install** — Follow the guide for your environment above.
2. **Create your first project** — [Step-by-step tutorial](/getting-started/first-project) walks you through a complete workspace.
3. **Learn the UI** — [UI Tour](/getting-started/ui-tour) shows you where everything is.

<Tip>
**Recommended path**

Start with the VS Code extension for the best experience — it includes Copilot integration, Command Palette access, and seamless file management.
</Tip>

## What you'll need

- **VS Code extension:** VS Code 1.85+ (or a compatible fork)
- **Browser app:** Any modern browser (Chrome, Firefox, Edge, Safari)
- No backend server or account required — ArchTect runs entirely client-side.
