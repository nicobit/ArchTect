ArchTect also runs as a standalone web application — no installation required.

## When to use the browser app

- Quick demos or presentations
- Trying ArchTect without installing VS Code
- Environments where VS Code extensions aren't available
- Sharing architecture diagrams with stakeholders via screen sharing

## Getting started

1. Open the ArchTect web app in your browser.
2. Create a new project or open an existing `.dsl` file.
3. The editor loads with the same canvas, inspector, and views as the VS Code extension.

![ArchTect browser app showing the three-panel layout with a populated System Landscape diagram](/images/screenshots/portal-guide/full-window-three-panel.png)

## Feature comparison

| Feature | VS Code Extension | Browser App |
|---|---|---|
| Visual canvas editor | Yes | Yes |
| DSL editor (Monaco) | Yes | Yes |
| Auto layout | Yes | Yes |
| PNG/SVG export | Yes | Yes |
| arc42 doc generation | Yes | Yes |
| Mermaid/PlantUML/Ilograph export | Yes | Yes |
| Copilot chat participant | Yes | No |
| MCP integration | Yes | No |
| Command Palette | Yes | Limited |
| File system access | Native | Upload/download |
| In-app AI chat | Yes | Yes |

<Note>
**Same core, different shell**

The browser app uses the same React frontend as the VS Code extension. The modeling, rendering, and export capabilities are identical.
</Note>
