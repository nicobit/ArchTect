---
title: Keyboard Shortcuts
description: Canvas and editing keyboard shortcuts in ArchTect.
---

| Shortcut | Action |
|---|---|
| `Ctrl+Z` | Undo |
| `Ctrl+Shift+Z` / `Ctrl+Y` | Redo |
| `Ctrl+S` | Save / apply changes |
| `Ctrl+0` | Fit view to all elements |
| `Ctrl+1` | Zoom to 100% |
| `Ctrl+` `+` | Zoom in |
| `Ctrl+` `-` | Zoom out |
| `Esc` | Deselect all |
| `Delete` | Delete the selected element or relationship |
| `Shift+click` | Multi-select |
| `Space` + drag | Pan the canvas |
| `Ctrl+A` | Select all |
| Arrow keys | Nudge the selected element(s) |
| `Ctrl+D` | Duplicate the selected element |

<Tip>
**This list covers the canvas**

For the full list of VS Code Command Palette commands, see [VS Code Commands](/reference/commands-vscode).
</Tip>
