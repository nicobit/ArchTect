title: Explorer
description: Browsing project files and folders in ArchTect.
---

The Explorer panel (the first icon in the [left rail](/portal-guide/left-rail)) shows your model's elements as a tree, grouped by the `group { }` blocks defined in your DSL — not a filesystem browser.

![Explorer panel listing model elements grouped by DSL groups](/images/screenshots/portal-guide/explorer-panel.png)

Use it to:

- Get an overview of how your model is organized into groups (e.g. "People", "External Systems")
- Expand a group to see the elements inside it
- Select an element to jump to it on the canvas and open it in the Inspector

**Expand** / **Collapse** at the top toggle every group open or closed at once.

<Note>
**For file management, use VS Code's Explorer**

This panel browses your architecture model, not your filesystem. In the VS Code extension, use VS Code's own Explorer sidebar to manage `.dsl` files and other project files on disk.
</Note>
