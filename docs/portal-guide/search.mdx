---
title: Search
description: Finding elements, relationships, and views in ArchTect.
---

The Search panel (left rail) lets you quickly find elements, relationships, and views across your workspace without scrolling through the Views panel or the DSL source.

![Search panel](/images/screenshots/portal-guide/search-panel.png)

Type a name, tag, or identifier to filter results. Click a result to select it — if it's an element or relationship, the canvas navigates to the view containing it and selects it; if it's a view, the view opens.

<Tip>
**Faster than scrolling the DSL**

For large workspaces, Search is usually faster than the Views panel's tree for jumping straight to a specific element.
</Tip>
