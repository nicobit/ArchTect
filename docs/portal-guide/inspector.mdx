title: Inspector

---

The Inspector is the right-side panel that shows and lets you edit properties for whatever is currently selected — an element, a relationship, or the view itself when nothing is selected.

![Inspector showing properties for a selected software system element](/images/screenshots/portal-guide/inspector-element-selected.png)

## Element or relationship selected

The Inspector shows three tabs:

| Tab | Contents |
|---|---|
| **Properties** | Identity (identifier, rename), Basics (name, description), Tags, Links (URL), Custom Properties (key/value pairs), Relationships |
| **Style** | Shape, color, and other visual overrides for this element |
| **Layout** | Position and sizing controls |

Fields like Name and Description commit as you type; tag and property changes take effect immediately. The Inspector header shows the element's type (e.g. `softwareSystem`) and an external-link icon to jump to its DSL source.

## View selected (nothing on canvas selected)

Click empty canvas space to deselect all elements — the Inspector switches to view-level settings across four tabs:

| Tab | Contents |
|---|---|
| **Properties** | Name, Identifier, Type, Description, Scope/root element, Source (Auto-generated or Defined in DSL) |
| **Content** | Include/exclude rules for what appears in this view |
| **Layout** | Auto-layout direction and the layout engine (Default, Graphviz, Dagre, ELK) |
| **Appearance** | Applied themes and visual settings for the view |

Views tagged `Auto-generated` in the Source section exist only in the running app; use **Add to DSL** to make them explicit and durable in your `.dsl` file. Views tagged `Defined in DSL` already have a corresponding block in your source and offer **Remove from DSL** instead.

## Editing workflow

1. Select an element, relationship, or view on the canvas (or click a view in the [Views panel](/portal-guide/views-panel)).
2. Edit the fields in the Inspector.
3. Most edits apply immediately; broader changes (like pasted DSL) need `Ctrl+S` — see [Canvas & DSL Editor](/portal-guide/canvas-and-dsl).

Changes made in the Inspector serialize back to the DSL automatically.

<Note>
**Tags drive styling**

Tags control which styles are applied to elements. Use the `styles { }` block in your DSL to define visual rules based on tags — editing tags in the Inspector changes how elements appear on the canvas.
</Note>
