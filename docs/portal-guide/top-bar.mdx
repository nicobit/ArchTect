The top bar runs along the very top of the window. On the left is a menu bar (**File**, **Edit**, **View**, **Architecture**, **Help**); on the right are quick-action icon buttons and the theme toggle.

## Menus

| Menu | Contents |
|---|---|
| **File** | **Import...** and **Export...** — import a workspace or export the current view |
| **Edit** | Undo, redo, and clipboard actions |
| **View** | Canvas display options (zoom, fit, minimap, panel visibility) |
| **Architecture** | Workspace-level actions — edit architecture info, validate, generate documentation |
| **Help** | Links to the user guide and diagnostics |

![File menu open, showing Import and Export](/images/screenshots/portal-guide/file-menu-open.png)

<Note>
**Export here vs. the toolbar Export button**

**File → Export** and the **Export** dropdown in the [canvas toolbar](/portal-guide/canvas-and-dsl) both lead to the same export formats — PNG, SVG, Mermaid, PlantUML, Ilograph, and arc42 documentation. See [Export & Documentation](/export).
</Note>

## Right-side controls

| Control | Purpose |
|---|---|
| **⌘** icon | Opens the [Command Palette](/portal-guide/command-palette) |
| Puzzle-piece icon | Opens the [Plugins](/plugins) panel |
| Theme toggle (**Light** / **Dark**) | Switches the editor's own UI theme — separate from the visual theme applied to your diagrams |
| Settings gear | Application-level settings |
