The **AI Chat** tab sits alongside the Inspector on the right side of the screen. It's an in-app AI assistant that can help you model and generate Structurizr DSL without leaving the editor.

![AI Chat panel with its empty state](/images/screenshots/portal-guide/ai-chat-panel.png)

## Using AI Chat

1. Click the **AI Chat** tab (next to **Inspector**) on the right panel.
2. Describe the architecture you want to build, or ask a modeling question, in the input box at the bottom.
3. Choose a mode from the dropdown (default: **Auto**) if your setup exposes multiple models or providers.
4. Review the suggested DSL before it's applied — accept or discard the change.

<Tip>
**VS Code also has a Copilot chat participant**

In the VS Code extension, you can also type `@archtect` in the GitHub Copilot chat to get the same kind of modeling help without switching panels. See [Copilot Chat Participant](/vscode-extension/copilot).
</Tip>

## What it's good for

- Scaffolding a new workspace from a plain-language description
- Adding elements, containers, or relationships to an existing model
- Explaining what a section of DSL does
- Suggesting fixes for validation errors

<Note>
**Review AI-generated DSL**

Treat AI Chat output as a draft. Review the generated DSL for accuracy — especially identifiers, relationship directions, and tags — before saving.
</Note>
