<Aside type="note">
**Executive summary:** ArchTect is a visual, AI-assisted IDE for Structurizr DSL — without breaking architecture-as-code principles.
</Aside>

## At a glance

<Card title="At a glance">
- DSL-first: Structurizr-compatible modeling
- Bidirectional canvas ↔ DSL editing
- Deterministic views and layouts
- AI-assisted modeling with Copilot
- Export to PNG, SVG, Mermaid, PlantUML, draw.io, Ilograph
- arc42 documentation generation
- MCP server + Copilot chat participant in VS Code
- Extensible via a plugin system
- Works as a VS Code extension or web app
</Card>

## Why ArchTect

- **Bidirectional canvas ↔ DSL editing.** Keep the model and diagram aligned without manual rework.
- **Opinionated modeling.** Clear, view-specific rules keep architecture consistent.
- **View-aware modeling.** System context, container, dynamic, and deployment views with stable view keys.
- **Deterministic outputs.** Stable serialization and predictable layouts support governance and review.
- **AI-assisted.** Copilot integration and in-app AI chat for modeling and documentation.
- **Rich export.** PNG, SVG, Mermaid, PlantUML, draw.io, Ilograph, and arc42 documentation generation.
- **Workflow flexibility.** Use the same workspace in VS Code or in the browser.

**Compared to code-only tools:** ArchTect adds a visual editor without losing DSL precision.
**Compared to visual-only tools:** ArchTect preserves a canonical DSL for traceability and governance.
