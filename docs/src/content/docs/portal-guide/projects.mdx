This page explains how to create and open ArchTect projects.

## Quick start

1. Create a `.dsl` file (e.g., `workspace.dsl`) with your architecture model.
2. Open it in VS Code.
3. Click the **ArchTect icon** in the editor title bar to open the visual editor.

That's it — no project setup wizard required.

## Opening a DSL file

### VS Code extension

| Method | Steps |
|---|---|
| **Editor title icon** | Open a `.dsl` file → click the ArchTect icon in the title bar |
| **Explorer context menu** | Right-click a `.dsl` file → **ArchTect: Open with ArchTect** |
| **Explorer context menu (folder)** | Right-click a project folder → **ArchTect: Open Project** |

### Browser app

1. Open the ArchTect web app.
2. Open or upload your `.dsl` file.

## Creating a new project

Use the Command Palette (`Ctrl+Shift+P`) → `ArchTect: New Project` to create a new workspace with a wizard. This generates a `.dsl` file with a basic structure.

<Aside type="tip">
**Templates**

If your workspace includes project templates, the wizard offers them. Choose a template to pre-populate views and elements.
</Aside>

## Save behavior

Changes you make on the canvas or in the DSL editor are synced bidirectionally — the underlying DSL is updated as you edit, and `Ctrl+S` applies the change and flushes it to disk.

| Environment | Save behavior |
|---|---|
| **VS Code** | The DSL content updates in real time as you edit on the canvas. The file tab shows as modified until you save; use `Ctrl+S` to flush to disk. |
| **Browser app** | `Ctrl+S` or the Save action writes changes to the project store. |

<Aside type="note">
**Conflicts**

When multiple editors modify the same `.dsl` file, the extension prompts to merge or accept one version.
</Aside>

## Recommended folder conventions

Use a straightforward structure so other tools (CI, exporters) can locate DSL files:

```
<project-root>/
├── workspace.dsl         # primary DSL file
├── models/               # reusable model fragments (optional)
└── docs/                 # generated documentation and exports
```

## Troubleshooting

<details>
<summary>File won't open / wrong editor</summary>

**Symptom:** double-clicking `.dsl` opens plain text rather than ArchTect.

**Fix:** Click the ArchTect icon in the editor title bar, or right-click the file → `Open With...` → choose `ArchTect`.
</details>

<details>
<summary>Missing commands in Command Palette</summary>

**Symptom:** `ArchTect: New Project` not listed.

**Fix:** Ensure the extension is enabled, reload the window (`Developer: Reload Window`), and confirm the extension has loaded.
</details>

<details>
<summary>Conflicting saves or merge prompts</summary>

**Symptom:** save triggers a conflict dialog.

**Fix:** Review both versions in the diff view, merge changes, and save. Consider using source control to manage concurrent edits.
</details>
