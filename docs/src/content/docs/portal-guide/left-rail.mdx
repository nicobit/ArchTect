---
title: Left Rail
description: The icon strip that switches between ArchTect's side panels.
---

import { Aside } from '@astrojs/starlight/components';

The narrow icon strip on the far left switches which panel is shown alongside the canvas. Only one panel is open at a time — clicking the active icon again collapses the panel.

| Icon | Panel | What it shows |
|---|---|---|
| Explorer | [Explorer](/portal-guide/explorer) | Model elements grouped by DSL `group { }` blocks |
| Views | [Views Panel](/portal-guide/views-panel) | Workspace structure and view list |
| Search | [Search](/portal-guide/search) | Find elements, relationships, and views |
| Palette | [Palette](/portal-guide/palette) | Drag-and-drop element creation and icon libraries |
| DSL | Canvas & DSL Editor | Opens the DSL editor as a tab |
| Plugins | [Plugins](/plugins) | Installed plugin list |

<Aside type="tip">
**Collapsing for more canvas space**

Click the highlighted rail icon again to collapse the left panel entirely — useful when reviewing a diagram and you don't need the panel open.
</Aside>
