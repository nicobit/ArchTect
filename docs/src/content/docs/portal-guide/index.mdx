## Common mistakes and troubleshooting

| Problem | Solution |
|---|---|
| Changes not visible after edit | Canvas and DSL sync automatically — press `Ctrl+S` to apply and flush to disk |
| Working in the wrong view | Check the active view name in the Views panel; DSL-authored views are tagged `DSL`, auto-generated ones `AUTO` |
| Inspector changes not applied | Make sure the element is selected — some fields commit on blur, others need `Ctrl+S` |
| View not showing expected elements | Check `include` / `exclude` rules in the view definition |
| Layout looks different after re-opening | Check the layout engine set per view in the Inspector's Layout tab |
