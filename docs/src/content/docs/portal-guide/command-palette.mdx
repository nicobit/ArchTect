The portal has its own command palette, opened from the **⌘** icon in the [top bar](/portal-guide/top-bar). Use it to quickly jump to actions without hunting through menus.

## VS Code extension

In VS Code, you also have the native Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`) — search for `ArchTect` to see the extension's commands: creating projects, exporting, generating documentation, validating the model, and configuring MCP integration.

See [VS Code Commands](/reference/commands-vscode) for the full list.
