All tests run via Vitest, from `frontend/`:

```bash
cd frontend
npm run test          # full suite
npm run test:smoke    # fast subset — dsl and ast tests only
npm run test:unit     # tests/unit
npm run test:integration  # tests/integration
npm run test:coverage # with coverage report
npm run test:watch    # watch mode
npm run test:ui       # Vitest UI
```

`npm run verify:quick` runs the smoke suite; `npm run verify:ci` builds and runs the smoke suite — these are the gates referenced in the root `CONTRIBUTING.md`.

## Extension verification

```bash
cd extension
npm run verify:quick  # compiles (build:webview + prepare:native-scanner + tsc)
```

<Aside type="caution">
**Always `cd frontend` first**

The repo root also has a Vitest config that resolves `frontend/tests/...` paths but lacks `globals: true` — running `npx vitest` from the repo root instead of `frontend/` silently uses the wrong config and produces spurious `ReferenceError: test is not defined` failures across many files. Always confirm you're in `frontend/` before running tests.
</Aside>
