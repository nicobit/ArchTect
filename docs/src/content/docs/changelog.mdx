## Latest

### Documentation

- Comprehensive user guide covering all view types, editing workflows, toolbar, inspector, and projects
- New export guides: Mermaid, PlantUML, Ilograph, and arc42 documentation generation
- DSL modeling guides: basics, relationships, views, dynamic views, filtered views, deployment views
- DSL Support Matrix documenting supported, parsed-only, and unsupported features
- Troubleshooting guides for validation errors, missing views, and VS Code webview issues
- VS Code commands reference and file types reference
- Getting started guides for VS Code extension and browser app
- UI tour with annotated interface walkthrough

### Features

- **Bidirectional editing** — Edit on the canvas or in the DSL editor; changes sync automatically
- **Multiple view types** — System Landscape, System Context, Container, Component, Dynamic, Deployment, Filtered, and Custom views
- **Deterministic layout** — Multiple layout engines (Default, Graphviz, Dagre, ELK) with per-view engine selection saved in the DSL
- **Rich export** — PNG, SVG, Mermaid, PlantUML, and Ilograph output formats
- **arc42 documentation generation** — Generate structured architecture docs from your model
- **AI-assisted modeling** — Copilot chat participant and in-app AI assistant
- **VS Code integration** — Native extension with Command Palette, Explorer context menu, and Copilot support
- **Browser app** — Standalone web application with the same core capabilities
- **Themes** — Built-in and external Structurizr themes with custom style blocks
- **Groups** — Named element boundaries with nesting support
- **Tags and properties** — Custom metadata for elements and relationships
- **Drag-and-drop editing** — Drag elements to reposition, drag to create relationships, nudge with arrow keys
