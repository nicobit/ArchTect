Export your architecture views as [PlantUML](https://plantuml.com/) diagram code — a widely-used text-based diagramming tool supported by Confluence, Javadoc, and many documentation pipelines.

## Why PlantUML

- **Enterprise ecosystem** — PlantUML is widely adopted in enterprise environments with existing rendering pipelines.
- **Confluence integration** — Paste directly into Confluence pages using the PlantUML macro.
- **CI/CD rendering** — Render diagrams in CI pipelines using the PlantUML server or CLI.

## How to export

1. Open the view you want to export.
2. Click **Export → PlantUML** in the toolbar.
3. The PlantUML code is generated and available for download or copy.

## Example output

A system context view might export as:

```plantuml
@startuml
!include https://raw.githubusercontent.com/plantuml-stdlib/C4-PlantUML/master/C4_Context.puml

Person(user, "User", "A user of the system")
System(system, "My System", "The system being modeled")

Rel(user, system, "Uses")

SHOW_LEGEND()
@enduml
```

## Rendering

PlantUML code can be rendered using:

- **PlantUML server** — [https://www.plantuml.com/plantuml](https://www.plantuml.com/plantuml)
- **PlantUML CLI** — `java -jar plantuml.jar diagram.puml`
- **Confluence macro** — Paste into a PlantUML block in Confluence
- **VS Code extension** — Use the PlantUML VS Code extension for live preview

<Aside type="note">
**Limitations**

PlantUML has its own styling and layout engine. The exported diagram may differ visually from the ArchTect canvas. Element shapes, colors, and layout will follow PlantUML conventions.
</Aside>
