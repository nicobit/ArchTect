ArchTect supports multiple export formats to share your architecture with any audience.

## Available formats

| Format | Type | Best for |
|---|---|---|
| [PNG](/export/images) | Raster image | Presentations, emails, documents |
| [SVG](/export/images) | Vector image | Scalable documentation, web embedding |
| [Mermaid](/export/mermaid) | Text-based diagram | Markdown docs, GitHub READMEs, wikis |
| [PlantUML](/export/plantuml) | Text-based diagram | Confluence, Javadoc, existing PlantUML toolchains |
| [draw.io](/export/drawio) | Editable diagram | Further editing in diagrams.net / draw.io |
| [Ilograph](/export/ilograph) | Interactive diagram | Interactive 3D architecture exploration |
| [arc42 Documentation](/export/arc42) | Structured Markdown | Architecture documentation deliverables |

## How to export

### From the toolbar

Click the **Export** dropdown in the canvas toolbar and choose a format — the file downloads (browser) or saves to the project folder (VS Code) immediately.

![Export dropdown showing PNG, SVG, Mermaid, PlantUML, draw.io, and Ilograph options](/images/screenshots/export/export-menu-open.png)

### arc42 documentation

Diagram exports (PNG/SVG/Mermaid/PlantUML/draw.io/Ilograph) come from the toolbar dropdown above. **Generating arc42 documentation** is a separate, workspace-level action — see [arc42 Documentation Generation](/export/arc42) for how to run it from the **Architecture** menu or the Command Palette.

<Aside type="note">
**Export scope**

Image and diagram exports (PNG, SVG, Mermaid, PlantUML, draw.io, Ilograph) capture the **currently active view**. arc42 documentation generation covers the entire workspace.
</Aside>
