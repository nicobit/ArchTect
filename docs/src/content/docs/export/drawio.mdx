Export the current view as a [draw.io](https://www.drawio.com/) (diagrams.net) file — useful when you need to hand off a diagram for manual editing outside ArchTect, or when a downstream tool only accepts draw.io/`.drawio` files.

**How to export:**

1. Open the view you want to export.
2. Click **Export → Export as draw.io** in the toolbar.
3. The `.drawio` file downloads (browser) or saves to the project folder (VS Code).

<Aside type="note">
**One-way export**

Like the other diagram export formats, this is a one-way conversion — edits made in draw.io don't sync back to your ArchTect model. Treat the exported file as a snapshot, not a linked copy.
</Aside>
