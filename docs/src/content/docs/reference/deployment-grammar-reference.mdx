## Syntax

### Deployment Environment
```dsl
deploymentEnvironment "<name>" {
  // deployment nodes, groups, relationships
}
```

### Deployment Node
```dsl
deploymentNode "<name>" ["description"] ["technology"] ["tags"] ["instances"] {
  // nested nodes, infrastructure nodes, groups, relationships
}
```

**Parameters:**
- **name**: Required, identifies the node
- **description**: Optional, describes the node's purpose
- **technology**: Optional, specifies the technology/platform
- **tags**: Optional, comma-separated tags (e.g., "Server,Linux")
- **instances**: Optional, number or range:
  - Numeric: `"3"` = exactly 3 instances
  - Range: `"1..N"` = auto-scaling from 1 to N
  - Range: `"0..5"` = from 0 to 5 instances

### Infrastructure Node
```dsl
infrastructureNode "<name>" ["description"] ["technology"] ["tags"] {
  // relationships, properties
}
```

**Parameters:**
- **name**: Required, identifies the infrastructure
- **description**: Optional, describes the infrastructure
- **technology**: Optional, specifies the technology/platform  
- **tags**: Optional, comma-separated tags

## Examples

### Simple Deployment
```dsl
workspace {
  model {
    deploymentEnvironment "Production" {
      deploymentNode "Web Server" "Primary server" "Ubuntu 20.04" "Server" {
      }
    }
  }
}
```

### Auto-scaling Deployment
```dsl
deploymentEnvironment "Production" {
  deploymentNode "Auto-scaling Group" "Web tier" "" "" "1..N" {
    deploymentNode "EC2 Instance" "Web server" "Amazon Linux 2" "Server"
  }
}
```

### Nested Infrastructure
```dsl
deploymentEnvironment "Production" {
  deploymentNode "AWS US-East-1" "AWS Region" "AWS" {
    deploymentNode "Availability Zone 1" {
      deploymentNode "Application Tier" "" "" "" "3" {
      }
    }
  }
}
```

### Infrastructure Node
```dsl
deploymentNode "AWS" {
  infrastructureNode "Load Balancer" "Routes traffic" "AWS ALB" "Infrastructure"
}
```

### Child Block Syntax
Alternative to positional parameters:
```dsl
deploymentNode "Server" {
  description "Web server"
  technology "Ubuntu 20.04"
  tags "Server" "Linux"
  instances "1..N"
}
```

### Multiple Environments
```dsl
workspace {
  model {
    deploymentEnvironment "Development" {
      deploymentNode "Docker" "Local dev" "Docker Desktop"
    }
    
    deploymentEnvironment "Production" {
      deploymentNode "AWS" "Cloud production" "AWS"
    }
  }
}
```

## Instance Ranges

| Syntax | Meaning | Use Case |
|--------|---------|----------|
| `"1"` | Exactly 1 instance | Single server |
| `"3"` | Exactly 3 instances | Fixed cluster size |
| `"1..N"` | Auto-scaling from 1 to N | Cloud auto-scaling |
| `"0..5"` | Range from 0 to 5 | Conditional scaling |
| `"2..10"` | Range from 2 to 10 | Min/max scaling |

## Common Patterns

### 3-Tier Architecture
```dsl
deploymentEnvironment "Production" {
  deploymentNode "Region" {
    deploymentNode "Presentation Tier" {
      infrastructureNode "Load Balancer"
    }
    deploymentNode "Application Tier" "" "" "" "1..N" {
    }
    deploymentNode "Data Tier" {
    }
  }
}
```

### Multi-Region
```dsl
deploymentEnvironment "Production" {
  deploymentNode "AWS US-East-1" "Primary region" "AWS" {
  }
  deploymentNode "AWS EU-West-1" "Secondary region" "AWS" {
  }
}
```

### Microservices
```dsl
deploymentEnvironment "Production" {
  deploymentNode "Kubernetes" "K8s cluster" "Kubernetes" {
    deploymentNode "Service A" "" "" "" "2..5" {
    }
    deploymentNode "Service B" "" "" "" "1..3" {
    }
  }
}
```

## Tips

1. **Empty Parameters**: Use `""` for empty intermediate parameters
   ```dsl
   deploymentNode "Server" "" "Ubuntu"  // description empty, technology set
   ```

2. **Tags**: Separate multiple tags with commas (no spaces)
   ```dsl
   deploymentNode "Server" "" "" "Linux,Production,Server"
   ```

3. **Nesting**: No depth limit on nested deployment nodes
   ```dsl
   deploymentNode "Region" {
     deploymentNode "Zone" {
       deploymentNode "Rack" {
         deploymentNode "Server" {
         }
       }
     }
   }
   ```

4. **Child Blocks**: Override positional parameters
   ```dsl
   deploymentNode "Server" "" {
     technology "Ubuntu 20.04"  // Overrides empty positional
   }
   ```
