## The same portal, wired into VS Code

The extension embeds the ArchTect portal as a custom editor for `.dsl` and `.nbc4` files, and adds Command Palette commands, a Copilot chat participant, and an embedded MCP server on top.

## What it adds beyond the browser app

| Capability | Details |
|---|---|
| [Commands](/vscode-extension/commands) | Full command surface in the Command Palette and ArchTect menu |
| [MCP Server Integration](/vscode-extension/mcp) | Exposes ArchTect's model as tools other AI clients (Claude Code, Copilot) can call |
| [Copilot Chat Participant](/vscode-extension/copilot) | `@archtect` in GitHub Copilot Chat, with `/tools`, `/context`, and `/route` subcommands |
| Native file handling | `.dsl` and `.nbc4` open directly in the ArchTect editor via VS Code's custom editor API |
| Sidebar view | An "ArchTect" activity bar entry listing DSL files (behind `archtect.showSidebar`) |

Everything else — the canvas, Inspector, Views panel, and so on — is the same [Portal Guide](/portal-guide) content whether you're in VS Code or the browser.
