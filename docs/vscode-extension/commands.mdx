## Always available (Command Palette)

These commands are always available in the Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`):

| Command | Description |
|---|---|
| `ArchTect: New Project` | Create a new workspace with wizard |
| `ArchTect: Open Generation Center` | Open the documentation generation center |
| `ArchTect: Open User Guide` | Open the ArchTect user guide |
| `ArchTect: Show Copilot Diagnostics` | Open a diagnostics document with webview environment state |

## File entry points

These are available from the VS Code UI, not the Command Palette:

| Command | Where | Description |
|---|---|---|
| `ArchTect: Open with ArchTect` | Editor title icon, Explorer context menu | Open a `.dsl` or `.nbc4` file in the visual editor |
| `ArchTect: Open Project` | Explorer context menu (folders) | Open a project folder in ArchTect |

<Note>
**The ArchTect icon**

When you open a `.dsl` or `.nbc4` file, the ArchTect icon appears in the editor title bar. Click it to open the visual canvas editor.
</Note>

## ArchTect menu commands (when editor is active)

These commands are available via the **ArchTect** menu in the menu bar when the ArchTect editor is open:

### File

| Command | Description |
|---|---|
| `ArchTect: Save` | Save the current project |
| `ArchTect: Export PNG` | Export the current view as a PNG image |
| `ArchTect: Export SVG` | Export the current view as an SVG image |
| `ArchTect: Export Diagram (Experimental)` | Export diagram in experimental format |

### View

| Command | Description |
|---|---|
| `ArchTect: Create View` | Create a new view in the workspace |
| `ArchTect: Open View in Canvas` | Open a view in the diagram canvas |
| `ArchTect: Toggle Explorer` | Show or hide the left panel |

### Architecture

| Command | Description |
|---|---|
| `ArchTect: Edit Architecture Info` | Edit workspace-level metadata |
| `ArchTect: Generate Documentation` | Generate arc42-structured documentation from the model |
| `ArchTect: Validate Architecture` | Run DSL validation and report errors |

## MCP commands

| Command | Description |
|---|---|
| `ArchTect: MCP Toggle Server` | Start or stop the embedded MCP server |
| `ArchTect: MCP Show Status` | Show MCP server status |
| `ArchTect: MCP Configure Client` | Configure MCP client integration for the workspace |
| `ArchTect: MCP Configure Claude Code` | Configure MCP for Claude Code |

See [MCP Server Integration](/vscode-extension/mcp) for what the server exposes.

## Background export

| Command | Description |
|---|---|
| `ArchTect: Export All Views as SVG (Background)` | Export all views as SVG files in the background |

## AI / Copilot

| Command | Description |
|---|---|
| `ArchTect: Keep Changes` | Accept pending AI-suggested changes |
| `ArchTect: Discard Changes` | Reject pending AI-suggested changes |

See [Copilot Chat Participant](/vscode-extension/copilot) for the `@archtect` chat commands.
