## Before you start

- Read [AGENTS.md](https://github.com/nicobit/Archtect/blob/main/AGENTS.md) for repository boundaries and ownership rules.
- Keep pull requests minimal in scope and covered by tests — see the root `CONTRIBUTING.md` for the full expectations.
