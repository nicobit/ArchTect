---
title: Installing Plugins
description: How plugins are registered and loaded in ArchTect.
---

Today, plugins are registered in code rather than installed through a marketplace or package manager — there's no plugin registry or remote-install flow yet. A plugin ships as part of a build (either the core ArchTect build or a fork/extension of it) and registers itself at startup:

```typescript
PluginManager.register({
  metadata: MyPlugin.metadata,
  loader: async () => MyPlugin,
  enabled: true,
  priority: 10, // optional, lower = earlier
})
```

Once registered, it shows up in the [Plugins panel](/plugins) where it can be activated or deactivated without restarting ArchTect.

<Note>
**No plugin marketplace yet**

Remote/dynamically-downloaded plugins aren't supported. If you need custom functionality, the plugin lives in your build's source alongside the ones ArchTect ships with.
</Note>
